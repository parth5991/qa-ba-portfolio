# ParthBlog

A blogging platform concept for personal blogging, developed as part of a QA and Business Analysis portfolio.

## Project Overview

ParthBlog is a blogging platform project designed to document functional requirements, user workflows, UI wireframes, and manual test cases. The project demonstrates the application of Business Analysis and Quality Assurance practices throughout the software development lifecycle.

## Project Progress

The following documentation and design deliverables have been completed or are currently in progress:

| No. | Deliverable | Status |
|---|---|---|
| 1 | Functional Requirements Specification | Completed |
| 2 | UML Flowcharts | Completed |
| 3 | UI Wireframes | Completed |
| 4 | Manual Test Cases | In Progress |

## Project Documentation

- **Functional Requirements:** Defines the system's features, business rules, and expected behavior.
- **UML Flowcharts:** Illustrates user workflows, decision points, and process logic.
- **UI Wireframes:** Provides visual representations of the website's screens and layouts.
- **Manual Test Cases:** Documents test scenarios, test steps, test data, expected results, actual results, and status.

## Notes

ParthBlog is currently a portfolio documentation and design project. A working website is not available, so the manual test cases have not been executed against a live application.
