# ParthBlog

A blogging platform concept for personal blogging, developed as part of a QA and Business Analysis portfolio.

## Project Overview

ParthBlog is a blogging platform project designed to document functional requirements, user workflows, UI wireframes, manual test cases, and requirements traceability. The project demonstrates the application of Business Analysis and Quality Assurance practices throughout the software development lifecycle.

The project covers 11 functional requirements supported by 202 documented manual test cases across 15 Excel worksheets.

## Project Documentation

- **Functional Requirements:** Defines the system's features, business rules, and expected behavior.
- **UML Flowcharts:** Illustrates user workflows, decision points, and process logic.
- **UI Wireframes:** Provides visual representations of the website's screens and layouts.
- **Manual Test Cases:** Documents test scenarios, test steps, test data, expected results, actual results, and status.
- **Requirements Traceability Matrix (RTM):** Maps the functional requirements to their corresponding test coverage and provides an overview of requirement-level coverage.

## Notes

ParthBlog is currently a portfolio documentation and design project. A working website is not available, so the manual test cases have not been executed against a live application.

All test cases remain in `Not Started` status. The RTM reflects documented test coverage and does not represent actual test execution results.

## Defect Reporting

Defect reporting is outside the current scope of this project because a working application is not available for test execution.

The project focuses on requirements documentation, business analysis, UI wireframes, manual test design, and requirements traceability.

No defects have been logged, as the documented test cases have not been executed against a live application.
