# ParthBlog – UI Wireframes

This folder contains the UI wireframes created for the ParthBlog project.

The wireframes represent the planned user interface and provide a visual reference for the website's main screens and user workflows. They support the project's business analysis and quality assurance activities by helping define screen layouts, navigation, and expected user interactions.

## Screens Included

### Authentication

1. Login
2. Sign Up
3. Forgot Password

### Home Page and Blog Viewing

4. Welcome Screen (Guest User)
5. Home Screen (Authenticated User)
6. Blogs Page
7. Individual Blog Page

### Blog Management

8. Publish Blog Page
9. Create/Edit Blog

### User Profile

10. Customize Profile
11. Edit Profile

### General Website Pages

12. FAQ
13. Contact Us

## Purpose

The wireframes serve as a visual reference for:

- Understanding page layouts and content placement.
- Reviewing navigation between screens.
- Identifying the main user interactions.
- Supporting functional requirements documentation.
- Designing representative manual test scenarios.

## Relationship to Other Project Documents

The wireframes form part of the ParthBlog QA and Business Analysis portfolio alongside:

- Functional Requirements Specification
- Manual Test Cases
- Future API Testing Documentation
- Future SQL Validation Documentation
